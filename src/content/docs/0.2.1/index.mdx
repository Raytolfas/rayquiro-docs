## Overview

RayQuiro is a compiled programming language with a dynamic runtime.
Runs on Windows and Linux. Designed for real applications.

```js
async fn main() {
    var now = datetime.now();
    print("RayQuiro " + str(now?.["year"]));
    print("ID: " + crypto.uuid());
}
main();
```

| Category | Names |
|----------|-------|
| **Built-ins** | `json`, `fs`, `env`, `process`, `datetime`, `path`, `hash`, `crypto`, `http`, `net`, `db`, `os`, `time` |
| **Modules** | `rayquiro.engine`, `rayquiro.web`, `rayquiro.ui`, `rayquiro.app` |
| **Packages** | Community packages via `rqio add` |
