RayQuiro includes a built-in package manager and native distribution system. Packages can be installed globally or locally per-project, hosted on GitHub or published to the official registry (`rq.raytolfas.cc`).

## Quick Start: Installing Packages

```bash
# Install from official registry:
rqio add telebot

# Install directly from GitHub:
rqio add username/repo

# Install locally into current project (.rqio/packages/):
rqio add telebot --local

# Restore all dependencies from rqio.json:
rqio install
```
