RayQuiro включает в себя набор встроенных функций, которые доступны глобально в любом скрипте без использования директивы `import`.

---

## 1. Базовые функции и вывод в консоль

| Функция | Сигнатура | Описание |
|---------|-----------|----------|
| `print` | `print(...args)` | Выводит аргументы через пробел в стандартный поток вывода с переводом строки. |
| `assert` | `assert(condition, message = "")` | Выбрасывает исключение, если условие ложно. |
| `type` | `type(value)` | Возвращает строковое имя типа: `"number"`, `"string"`, `"bool"`, `"array"`, `"object"`, `"function"` или `"null"`. |

```rayquiro
print("Привет", 42, true);
assert(2 + 2 == 4, "Ошибка математики!");
print(type("текст"));
print(type([1, 2]));
```

---

## 2. Преобразование типов

| Функция | Сигнатура | Описание |
|---------|-----------|----------|
| `str` | `str(value)` | Преобразует любое значение в строку (псевдоним: `to_string`). |
| `to_string` | `to_string(value)` | Эквивалентно `str(value)`. |
| `num` | `num(value)` | Парсит строку или логическое значение в число. |
| `bool` | `bool(value)` | Приводит значение к логическому типу (`true` / `false`). |

```rayquiro
var n = num("3.1415");
var s = str(100);
var b = bool(1);
```

## 3. Коллекции, массивы и объекты

| Функция | Сигнатура | Описание |
|---------|-----------|----------|
| `len` | `len(container)` | Возвращает длину строки, количество элементов массива или ключей объекта (псевдоним: `length`). |
| `length` | `length(container)` | Эквивалентно `len(container)`. |
| `range` | `range(stop)` / `range(start, stop, step = 1)` | Генерирует массив чисел от `start` до `stop`. |
| `push` | `push(array, value)` | Добавляет элемент в конец массива. |
| `pop` | `pop(array)` | Удаляет и возвращает последний элемент массива. |
| `join` | `join(array, separator = "")` | Объединяет элементы массива в строку с разделителем. |
| `split` | `split(str, separator = "")` | Разделяет строку по разделителю в массив подстрок. |
| `keys` | `keys(object)` | Возвращает массив ключей объекта. |
| `values` | `values(object)` | Возвращает массив значений объекта. |

```rayquiro
var items = [10, 20, 30];
push(items, 40);
print("Длина: " + str(len(items)));

var text = join(["Ray", "Quiro"], " ");
print(text);
```

## 4. Строковые утилиты

| Функция | Сигнатура | Описание |
|---------|-----------|----------|
| `upper` | `upper(str)` | Преобразует строку в верхний регистр. |
| `lower` | `lower(str)` | Преобразует строку в нижний регистр. |
| `trim` | `trim(str)` | Удаляет пробельные символы в начале и конце строки. |
| `contains` | `contains(str, substr)` | Проверяет, содержится ли подстрока в строке. |
| `replace` | `replace(str, search, repl)` | Заменяет все вхождения `search` на `repl`. |
| `slice` | `slice(str, start, end)` | Возвращает подстроку или срез массива. |

## 5. Математические функции

| Функция / Константа | Сигнатура | Описание |
|---------------------|-----------|----------|
| `pi` | константа `3.1415926535...` | Число Пи. |
| `sqrt` | `sqrt(x)` | Квадратный корень из числа. |
| `abs` | `abs(x)` | Абсолютное значение (модуль). |
| `pow` | `pow(base, exp)` | Возведение числа в степень. |
| `sin` | `sin(rad)` | Синус угла в радианах. |
| `cos` | `cos(rad)` | Косинус угла в радианах. |
| `tan` | `tan(rad)` | Тангенс угла в радианах. |
| `log` | `log(x)` | Натуральный логарифм. |
| `min` | `min(a, b)` | Минимальное из двух чисел. |
| `max` | `max(a, b)` | Максимальное из двух чисел. |
| `clamp` | `clamp(x, min, max)` | Ограничение числа диапазоном. |
| `floor` | `floor(x)` | Округление вниз до ближайшего целого. |
| `ceil` | `ceil(x)` | Округление вверх до ближайшего целого. |
| `round` | `round(x)` | Округление до ближайшего целого. |
| `random` | `random(min?, max?)` | Генерация случайного числа. |

```rayquiro
print("Корень из 16: " + str(sqrt(16)));
print("2 в степени 8: " + str(pow(2, 8)));
print("Пи: " + str(pi));
```
