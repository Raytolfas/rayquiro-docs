| Built-in | Description |
|----------|-------------|
| `json` | Parse and serialize JSON |
| `regex` | Regular expressions (test, match, replace, split) |
| `fs` | File system |
| `env` | Environment variables |
| `process` | Args, exit, pid, cwd |
| `datetime` | Date and time |
| `path` | Path manipulation |
| `hash` | SHA-256, SHA-1 |
| `crypto` | MD5, Base64, UUID, HMAC, random |
| `http` | HTTP requests |
| `net` | TCP/UDP sockets |
| `db` | Database access |
| `os` | Platform, arch, hostname |
| `time` | Sleep, millisecond timer |
