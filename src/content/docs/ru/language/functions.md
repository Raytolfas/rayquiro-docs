---
title: Функции (fn)
description: Полное руководство по определению функций, параметрам, замыканиям, аргументам по умолчанию и возвращаемым значениям в RayQuiro.
---

Функции в RayQuiro являются объектами первого класса (first-class citizens). Их можно сохранять в переменные, передавать в качестве аргументов в другие функции, возвращать из функций, а также выполнять синхронно или асинхронно.

---

## 1. Объявление функций (`fn`)

Функции объявляются с помощью ключевого слова `fn`, за которым следует имя функции, список параметров в круглых скобках и тело функции в фигурных скобках:

```rayquiro
fn add(a, b) {
    return a + b;
}

var sum = add(10, 25);
print("Сумма: " + str(sum));
```

Если выполнение функции завершается без оператора `return`, функция неявно возвращает `null`.

---

## 2. Значения параметров по умолчанию

Для параметров можно задавать значения по умолчанию. Если вызывающий код опускает аргумент, используется значение по умолчанию:

```rayquiro
fn greet(name = "Мир", prefix = "Привет") {
    return prefix + ", " + name + "!";
}

print(greet());
print(greet("Алиса"));
print(greet("Боб", "Добрый день"));
```

---

## 3. Переменное число аргументов (`...rest`)

Функции могут принимать произвольное число аргументов, если перед последним параметром указать троеточие `...`:

```rayquiro
fn sum_all(...numbers) {
    var total = 0;
    var i = 0;
    while (i < len(numbers)) {
        total = total + numbers[i];
        i = i + 1;
    }
    return total;
}

print(sum_all(1, 2, 3, 4, 5));
print(sum_all(10, 20));
```

---

## 4. Анонимные функции и лямбды

Функции можно объявлять анонимно и передавать как аргументы (например, коллбэки для кнопок UI или обработчиков событий):

```rayquiro
var square = fn(x) {
    return x * x;
};

print(square(6));

var btn = ui.button("Нажми меня", fn() {
    print("Кнопка нажата!");
});
```

---

## 5. Замыкания (Closures)

Функции сохраняют доступ к переменным из внешней области видимости, в которой они были созданы:

```rayquiro
fn make_counter(start = 0) {
    var count = start;
    return fn() {
        count = count + 1;
        return count;
    };
}

var counter = make_counter(10);
print(counter());
print(counter());
```

---

## 6. Множественный возврат значений

Функции могут возвращать несколько значений через запятую, которые можно деструктурировать при присваивании:

```rayquiro
fn get_user() {
    return "admin", "admin@example.com", true;
}

var [username, email, is_admin] = get_user();
print("Пользователь: " + username + " (" + email + "), Админ: " + str(is_admin));
```
