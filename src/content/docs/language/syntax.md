title: Syntax
description: Core syntax of RayQuiro.
---

## Variables

```js
var name = "Alice";
var age  = 25;
var flag = true;
var none = null;
```

## Constants

```js
const PI = 3.14159;
```

## Comments

```js
// line comment
/* block comment */
```

## Semicolons — optional

```js
var a = 1
var b = 2
print(a + b)
```

## Strings

Single or double quotes. Escapes: `\n`, `\t`, `\\`

## Truthiness

Falsy: `null`, `false`, `0`, `""`
