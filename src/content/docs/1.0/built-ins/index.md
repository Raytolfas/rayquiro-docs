RayQuiro provides a standard library and built-in global namespaces:

* **[Standard Library & Global Functions](/1.0/built-ins/standard-library)**: `print`, `assert`, `len`, `str`, `num`, `bool`, `type`, `range`, `push`, `pop`, `map`, `filter`, `reduce`, `sqrt`, `sin`, `cos`, `pow`, `pi`, `sleep`, and more.

## Namespaces

| Built-in | Description |
|----------|-------------|
| `json` | Parse and serialize JSON |
| `regex` | Regular expressions (test, match, replace, split) |
| `fs` | File system |
| `env` | Environment variables |
| `process` | Args, exit, pid, cwd |
| `datetime` | Date and time |
| `path` | Path manipulation |
| `hash` | SHA-256, SHA-1 |
| `crypto` | MD5, Base64, UUID, HMAC, random |
| `http` | HTTP requests |
| `net` | TCP/UDP sockets |
| `db` | Database access |
| `os` | Platform, arch, hostname |
| `time` | Sleep, millisecond timer |
| `random` | Pseudo-random numbers, choices, shuffling |
| `ffi` | Dynamic C-ABI library loading and function calls (.dll, .so) |
| `buffer` | Raw contiguous byte buffers for memory manipulation |
